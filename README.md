# dding-marketplace

Claude Code plugin marketplace by CDDing.

## Installation

```bash
/plugin marketplace add CDDing/dding-marketplace
```

## Plugins

### [daily-log](./plugins/daily-log)

Automatically log and summarize your daily Claude Code activity.

- **Local mode** — Summarize logs locally using Claude CLI. No server needed.
- **Server mode** — Send logs to your own server for processing.

```bash
/plugin install daily-log@dding-marketplace
```
